# Diab Gebäudereinigung

A modern multilingual website for **Diab Gebäudereinigung**, built with Next.js and deployed on Vercel.

## Live Website

[https://diab-reinigung.de](https://diab-reinigung.de)

## Features

- Multilingual support in German, English, and Arabic
- Responsive design for desktop, tablet, and mobile
- RTL support for Arabic
- Service overview pages
- Company information
- Contact section
- Legal notice and privacy policy
- SEO metadata
- Sitemap and robots configuration
- Optimized images with Next.js
- Automatic Vercel preview deployments for pull requests

## Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- next-intl
- Vitest
- Vercel

## Getting Started

Install the dependencies:

```bash
npm ci
```
